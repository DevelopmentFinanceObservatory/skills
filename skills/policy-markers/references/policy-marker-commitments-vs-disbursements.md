# Reporting commitments vs. disbursements

What this covers: OECD guidance on whether to use commitments or disbursements when analysing policy marker data, and how SEEK/Donor Tracker practice differs from the OECD default.

## When to use this reference

The user asks whether to use commitments or disbursements for a policy marker analysis.

## OECD guidance on policy markers

The OECD applies policy markers to commitments, not disbursements.

The OECD's rationale, stated in the CRS Statistical Reporting Directives and the gender and climate marker handbooks, is that markers:

- Capture the policy intention of donors at the design stage of projects and programmes.
- Reflect changing political commitments over time, since commitments fluctuate as policies change.
- Are assigned at the point of project design, which corresponds to the commitment stage, not the disbursement stage.

As a result, the OECD's own published analyses of policy marker data — including the annual DAC statistical charts on gender equality and climate — are based on commitments.

## Our default

Our analyses use disbursements, not commitments.

The rationale:

- Disbursements represent money actually spent in a given year, which is more meaningful for tracking actual financial flows.
- Disbursements are less volatile than commitments for multi-year projects.
- Disbursements align better with the question most users are asking: "How much did this donor actually spend on gender equality last year?"
- In practice, donors report and screen markers against what was actually disbursed, and disbursements answer the practical question of how much a donor spent in a given year, which is the basis of our donor-level analysis.

## How to approach it

Use disbursements unless there is a specific reason to use commitments. Disbursements better reflect actual financial flows in a given year.

Use commitments only when:

- The user explicitly asks about donor pledges or policy intentions rather than actual spending.
- The analysis requires data before 2009 (disbursement data with gender markers is not available before 2009).
- The user is replicating or comparing against an OECD-published figure that uses commitments.

## What a good answer looks like

When advising on commitments vs. disbursements:

1. State the OECD default (commitments) and the reason (policy intention at design stage).
2. State our default (disbursements) and the reason (actual flows in a given year).
3. Recommend disbursements for the current analysis unless there is a specific reason to use commitments.
4. Note the availability constraint: disbursement data with gender markers starts from 2009.
5. If the user will compare figures to OECD publications, flag that the figures will differ and explain why.
