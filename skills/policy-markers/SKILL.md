## Overview

Use this skill when the task involves:

- The user asks what a policy marker is or how the system works.
- The user wants to know which policy markers are available and what each covers.
- The user asks how to score an activity (principal, significant, not targeted, not screened).
- The user asks about the difference between not targeted and not screened.
- The user asks whether to use commitments or disbursements for policy marker analysis.
- The user wants to analyse ODA flows by policy objective (e.g. gender equality, climate, nutrition).
- The user asks about limitations or caveats of policy marker data.

## Example

**Example Question:** "How much ODA did Germany disburse for gender equality in 2022, and does that include projects where gender was only a secondary objective?"

**Answer:** This question requires the gender policy marker. Load [references/policy-marker-general.md](references/policy-marker-general.md) to confirm the marker applies, [references/policy-marker-scoring.md](references/policy-marker-scoring.md) to explain the principal/significant distinction, and [references/policy-marker-commitments-vs-disbursements.md](references/policy-marker-commitments-vs-disbursements.md) to confirm disbursements are the right measure for this analysis.
